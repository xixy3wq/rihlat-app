# رحلات

منصة حجز رحلات ترفيهية بالعربية: صفحات الرحلات، الحجز والدفع الإلكتروني (ميسّر: أبل باي، مدى، البطاقات، STC Pay)، التذاكر برمز QR، الفاتورة الضريبية المبسطة، ولوحة إدارة كاملة.

- التشغيل محليًا: `npm install` ثم اضبط `.env` (انظر CLAUDE.md) ثم `npm run build && npm start`.
- بيانات تجريبية: `node prisma/seed-demo.mjs`.
